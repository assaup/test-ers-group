# 002. Встроенный `node:sqlite` и SQL без ORM

**Статус:** принято

## Контекст

Стек задан: SQLite. Нужен драйвер и способ описывать схему. Важно, чтобы проверяющий запустил проект
одной командой на любой ОС, без сборки нативных модулей.

## Решение

- Драйвер — встроенный модуль `node:sqlite` (`DatabaseSync`). В Node 24+ он работает без флагов;
  проект требует Node 24+, в `.nvmrc` — 26.
- Схема и запросы — обычный SQL. Миграции — упорядоченный массив `{ id, sql }` в коде, применённые
  отмечаются в таблице `migrations`.
- Весь SQL живёт в `*.repository.ts`, наружу отдаются типизированные объекты.

## Альтернативы

- **better-sqlite3** — тот же синхронный API, но нативный модуль: нужны prebuilt-бинарники под
  версию Node или компилятор. npm 11 к тому же по умолчанию блокирует install-скрипты, и установка
  требует ручного разрешения.
- **Prisma / Drizzle / TypeORM** — типизация и миграции «из коробки», но лишний слой для четырёх
  таблиц, а SQL на собеседовании объяснить проще, чем внутренности ORM.

## Последствия

- Ноль нативных зависимостей: `npm install` работает одинаково на Windows, macOS, Linux и в CI.
- Синхронный API: запросы короткие, а у SQLite один писатель — асинхронность ничего бы не дала.
- Типы строк из БД приводятся вручную в репозиториях — это осознанная цена отказа от ORM.
